## 6. Workflow Statuses

Per blueprint §1.6. v7.2.0-REM issues use the standard set:

- `Triage` — Newly filed. v7.2.0-REM creation lands here.
- `Backlog` — Triaged, awaiting sprint planning.
- `Todo` — Scheduled into current sprint cycle.
- `In Progress` — Active authoring / engineering.
- `In Review` — PR open; peer + adversarial review per Master Spec §M.4.6.
- `Done` — Merged; canonical defect ledger transition recorded.
- `Cancelled` — Superseded / re-scoped.

**Status-to-defect-ledger binding.** When a PROD-CRIT issue moves `In Review` → `Done`, the canonical `_audit/DEFECT_LEDGER.md` row transitions `open → remediated YYYY-MM-DD`. Supplementary tables MUST NOT carry the closure alone (D-CONS-001 P1 closure discipline; see Verdict §1 counterfactual #3).
