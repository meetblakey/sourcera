## Conventions

- **ID prefixes.** `SUM-###` = delta from `Sourcera_Master_Summary.md`. `KB-###` = delta from `KB_Engineering_Spec.md`. One row per distinct concept.
- **Status.** `MISSING` = absent from v6.0.0. `EXTENDS` = partial or under-detailed in v6.0.0 relative to source. `CONFLICTS` = source contradicts v6.0.0; the Summary (dated 2026-04-14, post-v6.0.0) wins per Authoring Convention #13, with every overwrite flagged.
- **Spec Target.** Existing `§X.Y` = extend in place. `NEW §X.Y` = author new subsection under the named parent. `NEW §N` = author new top-level section. `NEW Appendix K` = author new appendix. Multiple targets listed when a concept touches several surfaces (e.g., data model + API + appendix).
- **Target Phase.** 1–13 per the Integration Program. See "Phase Totals" at bottom for coverage verification.
- **Size.**
  - **S** — single row/paragraph/enum value/AC bullet, ≤40 lines.
  - **M** — authored subsection with field table or protocol + AC, 40–150 lines.
  - **L** — authored multi-subsection section or significant rewrite, 150–400 lines.
  - **XL** — new top-level section, new appendix, or cross-cutting primitive touching data model + API + webhooks + enums + AC, 400+ lines.
